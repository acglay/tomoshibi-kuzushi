# ともしび くずし — 面白さの設計(M0)

暗闇のブロック崩し。光の計算は2D Radiance Cascades(RC)。**ボールが光源**で、ブロックは照らされるまで見えない。

## 1. 狙う体験(GAME-FUN-LAYERS の番号)
1. **4 緊張と緩和(ためて一気に解放)**: 落ちてくる光の粒をパドルで受けてためる → 満タンで🔆「おおともしび」を放つと、ボールの位置で大閃光。**光が届いたブロックだけが焼け落ちる**(RCの明るさを読み戻して判定=影に隠れたブロックは残る)。
2. **6 発見・探索**: 暗い盤面をボールの光で探る。一度照らしたブロックは輪郭がしばらく残る(=見つけた記憶)。灯籠ブロックはかすかに灯っていて、壊すと周りがぱっと明るくなって配置が一気に見える。
3. **9 感覚の快**: マルチボール=光源が増えて画面が明るくなる。何個に増えても重くならない(RCは光源の数にコストが比例しない)。

## 2. 候補案と選んだ理由
メモリ game-fun-design-process(2026-09-27改訂)と APP-STANDARDS §5b に従い、点数表で決めずに「世界の中の理屈でつながるか」「ためて一気に解放があるか」で選んだ。ボットは詰み・クリア時間・残り方の計測にだけ使う。

| 案 | 中身 | 判断 |
|---|---|---|
| A 光で焼く大閃光(採用) | 粒を受けてため→ボール位置で大閃光→**照らされたブロックが焼ける**。影の中は残る | ためて解放そのもの。どこで放つか(ブロックの群れの奥まで入った瞬間)に上達の余地。RCの影がそのままルールになる |
| B 暗いブロックは壊れない | 照らされている間だけ当たり判定がある | 罰が先に立つ。見えない物にボールがすり抜けるのは「ずるい」に見える。不採用 |
| C ため撃ちパドル | パドルを止めて長押しでボールに光をため、明るさ=貫通力 | 操作が増える(片手ドラッグと両立しにくい)。光が当たり判定に効かない。不採用 |
| D 暗闇撃ちボーナス | 見えていないブロックを壊すと高得点 | 点数が増えるだけで世界が変わらない。不採用 |

## 3. 核のルール(世界の理屈)
- ボールは光。ブロックは光をさえぎる(影を落とす)。照らされた面のあるブロックだけが見える。
- ブロックが壊れると光の粒がこぼれて重力で落ちる(灯籠ブロックはたくさん)。粒はパドルで受けると🔆ゲージにたまる(取り逃した粒は床で消える)。
- 🔆満タンで放つ → ボールの位置で大閃光 BURST_T 秒。そのあいだ、RCで読んだ各ブロックの明るさ×時間が熱になり、HEAT_TO_BREAK を超えたものが焼け落ちる(焼け落ちた分の粒も落ちる=連鎖)。
- 💠玉ブロックを壊すとボールが2つ増える(=光源が増える)。全部落としたらライフ1つ減る。
- ブロック種: ふつう / かたい(2回)/ 🏮灯籠(かすかに灯る・壊すと周りを照らす+粒たくさん)/ 💠玉(マルチボール)

## 4. つまみ
`lib/tuning.ts`: BALL_* (速さ・明るさ)、PADDLE_*、GRAIN_*(落ちる粒)、GAUGE_MAX、BURST_*(大閃光の明るさ・時間)、HEAT_*(焼ける閾値)、SEEN_*(見えた判定と記憶の残り時間)、LANTERN_*、STAGE_*(盤面生成)。
